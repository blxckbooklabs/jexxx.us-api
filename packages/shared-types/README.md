# @blackbook/shared-types

Shared TypeScript type definitions

## Installation

```bash
npm install @blackbook/shared-types
```

## Usage

```typescript
import { /* exports */ } from '@blackbook/shared-types';
```

## Development

```bash
# Build the package
npm run build

# Watch for changes
npm run dev

# Run tests
npm test
```

## Contributing

This package is part of the Blackbook shared component ecosystem. Please follow the established patterns and conventions when contributing.
