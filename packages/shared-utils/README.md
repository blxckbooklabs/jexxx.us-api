# @blackbook/shared-utils

Shared utility functions and helpers

## Installation

```bash
npm install @blackbook/shared-utils
```

## Usage

```typescript
import { /* exports */ } from '@blackbook/shared-utils';
```

## Development

```bash
# Build the package
npm run build

# Watch for changes
npm run dev

# Run tests
npm test
```
